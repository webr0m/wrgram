## Privacidad: información para redactar la política

- WRGram conecta directamente con Telegram mediante TDLib. No retransmite chats a la API de Webrom ni a proveedores de IA.
- Se usa el teléfono para iniciar sesión, junto con el código y, si corresponde, la contraseña 2FA. No se registran en logs de WRGram.
- Telegram recibe los datos de cuenta, mensajes, dispositivo/conexión y demás información necesaria según su [política](https://telegram.org/privacy). Los chats cloud **no son chats secretos ni cifrado extremo a extremo**.
- La base de datos local de TDLib se cifra; la clave se protege con Android Keystore. El hardware de protección concreto depende del dispositivo. Cifrar no protege frente a todo malware, dispositivos comprometidos o una sesión desbloqueada.
- Las notas son opcionales, locales y cifradas; no se sincronizan ni se envían a Telegram. Se borran desde su chat; desinstalar elimina los datos locales.
- No hay analítica ni publicidad propia. La app accede a la agenda solo si el usuario activa la sincronización, usa la cámara del sistema al elegir «Tomar foto», pide permiso de micrófono al grabar una nota de voz y solo obtiene la ubicación al pulsar «Compartir ubicación». Esos datos se envían a Telegram, no a servidores de WRGram.
- Desde alpha02, WR IA consulta el estado del servicio HTTPS de WRGram. Solo al aceptar y pulsar Consultar se envían las instrucciones propias y el historial de esa conversación de IA al servidor y al proveedor Groq explícito. No se adjuntan chats ni notas de Telegram. La generación pública permanece deshabilitada; no hay clave de proveedor en Android ni respaldo automático. Revocar vacía el historial local, no elimina datos ya enviados al proveedor.
- Las notas personales de WR IA se guardan cifradas en el dispositivo, separadas de las notas por cuenta/chat; se pueden borrar desde WR IA y no se adjuntan automáticamente a consultas.
- Desde alpha03, React se distribuye dentro del APK en un origen local restringido. El puente solo admite comandos explícitos y archivos registrados, no rutas, credenciales ni peticiones TDLib arbitrarias. La búsqueda de GIF comparte el término con el bot configurado por Telegram, no con WR IA ni con los futuros complementos premium.
- El selector de documentos de Android permite copiar un archivo que el usuario elige al almacenamiento privado para enviarlo tras confirmación. La base de sesión y notas se cifran; no se afirma que los archivos multimedia descargados/importados estén cifrados por TDLib. No entran en backups. Una exportación elegida por el usuario crea una copia fuera del almacenamiento privado; no se permite para contenido protegido.
- Cerrar sesión solicita a Telegram revocar este acceso; desinstalar por sí solo no garantiza revocar la sesión remota. Se puede revocar desde Dispositivos en Telegram oficial.
- La app no crea cuentas propias de WRGram. No permite eliminar una cuenta de Telegram; no confundirlo con cerrar sesión. Revisar las obligaciones de eliminación de cuentas que correspondan antes de publicar.
- Contacto técnico: `https://t.me/webrom_bot`. Política pública vigente y contacto de privacidad: https://wrgram.webrom.cc/android/privacy/ y ridrogo@gmail.com. Revisar avisos y obligaciones aplicables antes de cambiar el tratamiento; no inventar domicilios ni certificaciones jurídicas.
